# Order Management Platform

A real-world microservices project built using Java,
Spring Boot, PostgreSQL, RabbitMQ, Docker and Kubernetes.

## Project Objectives

- Build RESTful microservices using Spring Boot.
- Implement asynchronous communication using RabbitMQ.
- Containerize applications using Docker.
- Orchestrate containers using Kubernetes.
- Implement CI/CD using GitHub Actions.
